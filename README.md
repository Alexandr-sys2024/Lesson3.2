# Игра "Тир" 🎯

## Описание
"Тир" — это простая игра на Pygame, где игрок должен кликать по мишени, которая после каждого попадания перемещается в случайное место. Игра длится 30 секунд, а сложность увеличивается, поскольку мишень становится меньше после каждого попадания.

## Как запустить игру
### 1. Установите зависимости
Убедитесь, что у вас установлен Python 3 и Pygame. Если Pygame не установлен, установите его командой:
```bash
pip install pygame
```

### 2. Запустите игру
Склонируйте репозиторий и выполните команду:
```bash
python main.py
```

## Управление
- Кликайте мышкой по мишени 🎯
- Каждое попадание уменьшает размер мишени и увеличивает счет
- Игра длится **30 секунд**
- В конце игры окно закрывается автоматически

## Требования
- Python 3.7+
- Pygame
